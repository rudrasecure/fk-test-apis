# Smart USB test exchange sets

Signed test update sets for the Rudra Secure ECDIS Smart USB firmware simulator test sequence.
All chart and permit files are dummy data. Generated by `tools/make_test_sets.py` in the firmware repo.

| Folder | Version | Expected result |
|---|---|---|
| `good42` | 42 | Accepted, becomes active |
| `tampered` | 43 | Rejected: PERMIT.TXT changed after signing (hash mismatch) |
| `badsig` | 43 | Rejected: signed with an unknown key |
| `oldver` | 41 | Rejected: older than the accepted version (anti-rollback) |
| `wrongvessel` | 43 | Rejected: manifest is for TEST-VESSEL-002 |
| `good43` | 43 | Accepted, switches to the other slot |

Firmware base URL: `https://raw.githubusercontent.com/rudrasecure/fk-test-apis/main/smart_usb/test_sets`

The manifests expire 35 days after generation; regenerate and push again after that.
